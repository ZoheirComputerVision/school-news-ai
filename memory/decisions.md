# القرارات الهندسية — الصوت المحلي

## القرارات الأساسية (مرحلة التأسيس — Phase 0)

| القرار | الخيار | البديل | السبب |
|--------|--------|--------|-------|
| **Runtime** | Node.js + Express | Next.js، Django | بساطة، سرعة تطوير، توافق مع HostingGuru |
| **قاعدة البيانات** | JSON (افتراضي) + SQLite | PostgreSQL، MongoDB | لا حاجة لـ SQL معقد حالياً، سهولة النشر |
| **الواجهة** | Vanilla HTML/CSS/JS | React، Vue | لا build step، نشر مباشر، أداء عالٍ |
| **المصادقة** | JWT + bcrypt | Session-based، OAuth | بدون حالة (stateless)، يناسب API |
| **النشر** | GitHub → HostingGuru | Vercel، Render | CI/CD تلقائي، استضافة مجانية |

## القرارات الفنية (مراحل لاحقة)

### تصميم Neo Vintage (Phase 2A)
- **هوية "الصوت المحلي"** بدلاً من "الجريدة الذكية"
- **نظام ألوان**: أبيض/أسود عالي التباين مع عنابي (#6B1D2A) وذهبي (#B8943C)
- **خطوط**: Amiri (نص)، Noto Kufi Arabic (عناوين)، Tajawal (عناصر)
- **تخطيط**: CSS Grid 3 أعمدة، responsive (2 tablet, 1 mobile)

### حوكمة التصميم (Phase 2A.2)
- **DESIGN_GOVERNANCE.md** وثيقة ملزمة — لا تغيير في الألوان/الخطوط/التخطيط

### بنية متعددة المنصات (Phase 3A)
- **عزل المحتوى**: tenant_id على جميع الجداول
- **توجيه URL**: /:slug/article/:id يوجه إلى المنصة الصحيحة
- **6 منصات افتراضية**: تيارت (افتراضي)، وهران، سطيف، الجزائر، مستغانم، الشلف

### نظام الفوترة (Phase 3C)
- **3 خطط**: Starter (مجاني)، Professional ($49)، Enterprise ($199)
- **تجربة 14 يوم**: اشتراك تجريبي تلقائي لكل منصة جديدة
- **الفوترة**: بدون بوابة دفع حالياً — أساس للربط المستقبلي مع Stripe/PayPal
- **MRR/ARR**: محسوب من الفواتير المدفوعة شهرياً
